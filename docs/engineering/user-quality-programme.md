## Completeness target

Target100% of predeclared required data after a query wherever obtainable. Separately
show actual data completeness and eligible source acquisition coverage, with whole
counts and dated denominators. Attempting all sources is not complete data. Do not
retroactively exclude unavailable/ambiguous measurements, fill zeros, average
incompatible solutions or create missing uncertainty to reach100%. Explicit N/A needs
a predeclared scientific reason. Query completion, enrichment completion, source
coverage and scientific readiness are different states; partial evidence supports
only operations whose prerequisites pass. Record missing items/reasons/follow-up.

## Interpretation and evidence safeguards

Explain why the implemented model flags or does not flag an object, what it compares,
which sources agree/conflict and what is actually established. NOT_FLAGGED is not
perfectly normal, and an anomaly is not an artificial object. A natural-model
consistency statement needs a valid specified model/fit; otherwise keep physical
origin unresolved. No plots, polished prose, code coverage, extra columns or synthetic
success substitute for independent scientific observations, compatible uncertainty,
calibration, multiple-testing/error control or predictive model comparison.

Before/after comparisons need frozen samples/comparators and declared thresholds.
Publish whole counts and per-condition results, not just pooled totals. Subjective
readability/design review and independent scientific/user evaluation remain distinct
from self-review and computational test success. Preserve prior datasets/results,
source bytes where permitted, versions and contradictions rather than rewriting them.
